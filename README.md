# Decode__labs

Data Cleaning and Preparation
About the Project

As part of my Data Analytics training, I worked on a data cleaning and preparation project using a marketing campaign dataset. The main goal of this project was to improve the quality of the dataset before performing any further analysis.

Real-world data is often incomplete and may contain missing values, duplicate records, or inconsistent formats. In this project, I explored the dataset, identified data quality issues, and applied appropriate techniques to clean and organize the data.

What I Did
* Examined the dataset structure and data types
* Identified missing values in the Income column
* Replaced missing values using the mean of the column
* Checked for duplicate records
* Verified that no duplicate records existed
* Converted the customer date column into a proper datetime format
* Saved the cleaned dataset for future analysis

Tools Used
* Python
* Pandas
* Google Colab

Project Files
* Data_Cleaning_Preparation.ipynb
* cleaned_marketing_campaign.csv
* Data_Cleaning_Preparation_Report.pdf

## What I Learned
This project helped me understand the importance of data cleaning in the data analysis process. I learned how to handle missing values, verify data quality, work with different data formats, and prepare a dataset for analysis. It also improved my practical experience with Python and Pandas.

Conclusion
After completing the cleaning process, the dataset became more reliable and ready for further analysis. This project gave me hands-on experience with one of the most important steps in the data analytics workflow.
