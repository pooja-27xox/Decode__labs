# Exploratory Data Analysis (EDA) on CardioGoodFitness Dataset
## Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on the CardioGoodFitness dataset. The main objective was to understand the dataset, identify patterns, analyze relationships between variables, and gain meaningful insights from the data.

EDA is an important step in data analytics because it helps us understand the characteristics of a dataset before applying advanced techniques or machine learning models.

Tools and Technologies Used
* Python
* Pandas
* Matplotlib
* Google Colab

Dataset
The dataset used for this project is the CardioGoodFitness dataset, which contains customer information related to fitness products, usage patterns, income, fitness levels, and miles covered.

Tasks Performed
* Loaded and explored the dataset
* Checked dataset structure and data types
* Analyzed missing values
* Calculated descriptive statistics such as mean, median, and standard deviation
* Identified minimum and maximum values
* Performed quartile analysis
* Created histograms to study data distribution
* Used boxplots to detect outliers
* Generated a correlation matrix and heatmap
* Summarized key findings and insights

Key Observations
* Customers with higher product usage tend to cover more miles.
* Fitness levels show a positive relationship with miles covered.
* Income has a moderate relationship with some fitness-related variables.
* Age shows a relatively weak correlation with most variables.
* The dataset provides useful insights into customer fitness behavior.

Conclusion
This project helped me understand the importance of Exploratory Data Analysis in the data analytics process. Through statistical analysis and visualization techniques, I was able to identify patterns, trends, and relationships within the dataset. The experience improved my practical skills in Python, data analysis, and data visualization.
